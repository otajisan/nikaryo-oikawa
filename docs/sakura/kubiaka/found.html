見つけたら（できること・できないこと）

2026-10-19 時点。連絡先は、必ず川崎市の公式ページで確かめてください 公式

市民がするのは「見る・撮る・記録する・知らせる」までです。木を傷つけること、薬、高い所の作業、生きた虫を運ぶことはしません。

見つけたときの手順

  1. 写真を撮る成虫、根元のフラス（近く）、木の全体、場所の分かる目印（公園名・施設名の看板など）。人・車のナンバー・表札は写さない。
  2. 成虫はその場でつぶす生きたまま持ち帰る・飼う・運ぶのは外来生物法で禁止されています。公式 子どもは素手で触らず、大人に任せます。
  3. 日時と場所を記録する公園・通り・用水の区間の名前など。
  4. 川崎市に知らせる下の窓口へ。迷ったら「疑い」として知らせれば十分です。

農地（ウメ・モモなど）で見つけたときは、神奈川県の農業技術センターにも相談できます。県全体の窓口は、環境農政局 緑政部 自然環境保全課（045-210-4310）です。公式

できること・してはいけないこと

やってよいことやってはいけないこと（理由）
公共の場所で、根元から目の高さまでを見て、フラスや成虫の写真を撮る生きた成虫・幼虫を持ち帰る・飼う・運ぶ・放す（外来生物法違反）公式
日時・場所・写真を記録して、市に知らせる他人の木・公共の木に、勝手に薬を入れる・まく（持ち主の同意と、登録どおりの使い方が必要。用水に流れ込むおそれもある）公式
見つけた成虫を、大人がその場でつぶすノミ・針金・ドリル・のこぎりで幹を削る・刺す（けがをする。木を傷つける。すべての木には管理者がいる）公式
ネットが巻かれた木で成虫を見つけたら、管理者に伝える脚立・木登り、弱った木の下に長くいること（落ちる。枝が落ちてくる）
「被害なし」も記録するネットを外す、ネットの中の成虫を逃がす・持ち帰る 公式
伐った木・枝を持ち帰る（中に幼虫がいることがある）
私有地・立入禁止の場所に入る

子どもと見回るときは

  • 大人が付き添い、2 人以上で動きます。用水の水辺側と車道側の転落、夏の熱中症に気をつけます。
  • 成虫は素手で触らず、持ち帰りません。死んだ虫を標本にして持ち運んでよいかは、確かめられていないので、勧めません。
  • 写すのは幹とフラスだけにします。SNS などに載せるときは、写真の位置情報を消し、人の顔・名前を出さないようにします。
  • 学校・子ども会などの活動で行うときは、保護者の同意を得てください。

ほかの通報の仕組み

環境省は「クビアカ発見・通報ネット（仮称）」を試行しています（2026-10-13〜11-30、2027-04 に本格運用の予定）。公式 川崎市の窓口との関係（どちらに出せばよいか）は、2026-10-19 時点で確かめられていません。要確認 このサイトでは、まず川崎市の窓口に知らせることを勧めます。
