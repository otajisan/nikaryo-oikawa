クビアカツヤカミキリとは

2026-10-19 時点の情報

中国などから来たカミキリムシです。幼虫が桜の幹の中を 2 年ほど食べ続け、木を枯らします。2018 年に「特定外来生物」に指定され、生きたまま飼う・運ぶ・放すことが法律で禁止されています。公式 Web

要点

  • 見つける手がかりは、桜の根元にたまる、うどんやかりんとうのような木くず（フラス）です。フラスは 4〜10 月ごろに出ます。公式 → 見分け方
  • 川崎市では、2026 年 6 月に宮前区の菅生緑地で見つかりました。その後、市内で新たに見つかったという公式の発表は、2026-10-19 時点でありません。二ヶ領用水沿いでの確認も公表されていません。公式 → 広がり方
  • いちばん確実な防除は、被害を受けた木を伐って根まで取り除くことです。用水のそばでは、薬を散布しないのが原則です。公式 → 防除の方法
  • 国が大きく動いています。2026 年 7 月に政府の対策本部ができ、9 月に防除戦略が決まり、10 月には予備費を使った交付金の追加公募が始まりました。公式 公式 → 仕組みと最新の動き
  • 市民ができるいちばん大事なことは、見回って、写真で市に知らせることです。→ 見つけたら

クビアカツヤカミキリを見つけたら

  1. 写真を撮る（成虫・根元の木くず〈フラス〉・木の全体・場所の分かる目印）
  2. 成虫はその場でつぶす。生きたまま持ち帰る・飼う・運ぶのは法律で禁止です 公式
  3. 川崎市に知らせる: 発見報告フォーム、メール 30kikaku@city.kawasaki.jp、電話 044-200-3720（環境局 総務部 企画課）公式

どんな木がやられるか

バラ科のサクラの仲間です。サクラ（ソメイヨシノ・オオシマザクラ・ヤマザクラ）、モモ（ハナモモを含む）、ウメ、スモモ、アンズなど。公式 公式 街の桜並木に多いソメイヨシノは、やられる本数がとくに多い木です。公式

どうなるか

幼虫が幹の内側（養分を運ぶ層）を食べると、その先の枝が枯れ、木が弱ります。幼虫が多いと 1 年〜数年で枯れることがあります。弱ったり枯れたりした木は、枝が落ちたり倒れたりして、人がけがをするおそれもあります。公式 公式
