みんなでできること

準備中のページです（2026-10-19 時点）

桜並木を守るには、早く見つけて、確実に市に届けることがいちばん大切です。散歩のついでの見回りでも力になります。地域の人と無理なく続けられる仕組みを、これから作っていきます。

見回りの考え方

  • 時期: 4〜8 月、とくにお盆過ぎ（8 月下旬）。公式 → 見回りカレンダー
  • 見るところ: 桜の根元を一周、目の高さまで。
  • 記録すること: 日付、区、場所（公園・施設・用水の区間の名前）、木の目印、症状（フラス・成虫・穴・枝枯れ）、写真の有無、通報した日、市の返事。「被害なし」も記録します。
  • グループで見回るとき: 見つけた人は写真を仲間に送り、市への通報は担当の 1 人がまとめて行うと、同じ木を何度も通報せずに済みます。

記録を公開するときの決まり

  • 公開するのは、公共の場所（公園・緑地・街路・河川沿い）の木の記録だけです。場所は区と施設名の単位までにします。
  • 私有地の木の位置、個人の名前・連絡先、人の顔・車のナンバー・表札が写った写真は公開しません。写真の位置情報（EXIF）は消します。
  • 市・県のページの文章や地図の画像はそのまま転載せず、リンクで示します。公式 確認された市町村などの事実は、出典と時点を添えて書きます。
  • 「確認」と「疑い」を分け、いつの情報かを必ず書きます。

ほかの地域の例

  • 埼玉県は、スマホの投稿フォームと公開地図で、県民から発見情報を集めています。「被害がない」という報告も受け付けています。公式
  • 群馬県の「ぐんまクビアカネット」は、成虫・フラス・穴の発見情報を投稿し、地図で見られるようにしています。公式
  • 横浜市は、見つかった公園のまわりの公園・街路樹・川を調べ、その結果を公表しました。公式

まだ分かっていないこと

このサイトで公開資料を調べても分からなかったことです。分かりしだい、このサイトに反映します。

  • 菅生緑地の被害木のその後と、周りの調査の結果
  • 二ヶ領用水沿いの桜 1 本ずつの管理者（川の土地・緑道・道路のどれか）と、点検・見回りの計画
  • 市民の見回りと市との協働の形（たとえば川崎市の河川愛護ボランティア制度で、桜の見回りを活動に含められるか）要確認
  • 国の通報ネットと川崎市の窓口の関係
  • 神奈川県の地域防除戦略と、川崎市の区分
  • 川崎市に、私有の木の防除への補助があるか

用水の清掃に参加する

一斉清掃・河川愛護ボランティア制度・ゴミの記録のしかたは、「用水のゴミ問題」にまとめています。

これからやること

  • 見回りの記録のしかた（記録の項目・写真の撮り方）をまとめる
  • 二ヶ領用水の水と生きもののページをつくる
  • 地域の人と一緒に続けられる見回り・観察の場をつくる
