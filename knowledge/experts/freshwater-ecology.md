# freshwater-ecology への上乗せ知識（nikaryo-oikawa）

## 前提
- プロジェクト: 「**武蔵小杉の二ヶ領用水にもオイカワを**」。二ヶ領用水をきれいにし、生きものと水辺の自然を守る
- 中心の区間: **中原区（武蔵小杉の周辺）**の二ヶ領用水。比べる相手として、オイカワが多い上流（多摩区の上河原線・宿河原線）も見る
- 目標の生きもの: **オイカワ**。オイカワがすみ、殖えるための条件（流れ・砂礫の底・隠れ場・水量・つながり）を軸に考える
- 魚を**放流しない**。環境の改善・清掃・外来種への対処・記録で目指す
- 成果は公開の repo に置く（workspace の CLAUDE.md の「公開 repo の作法」）。位置は橋・公園・親水施設の名前の単位まで
